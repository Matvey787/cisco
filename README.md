# Команды

`<>` - подставляемое значение  
`[]` — необязательный параметр

## Cisco IOS

| Общий синтаксис | Назначение | Презентация и слайд |
|---|---|---|
| `enable` | Переводит из пользовательского режима EXEC в привилегированный. | [ITN 2–3](tasks/ITN_Module_2-3.pptx), 8 |
| `configure terminal` | Открывает режим глобальной конфигурации. | [ITN 2–3](tasks/ITN_Module_2-3.pptx), 8 |
| `hostname <имя>` | Задаёт имя устройства. | [ITN 8–10](tasks/ITN_Module_8-10.pptx), 31 |
| `interface <тип> <номер>` | Открывает режим настройки указанного интерфейса. | [ITN 8–10](tasks/ITN_Module_8-10.pptx), 34 |
| `ip address <IPv4-адрес> <маска>` | Назначает интерфейсу IPv4-адрес и маску подсети. | [ITN 8–10](tasks/ITN_Module_8-10.pptx), 33–34 |
| `shutdown` | Административно отключает интерфейс. | [SRWE 10–13](tasks/SRWE_Module_10-13.pptx), 25 |
| `no shutdown` | Снимает административное отключение интерфейса. | [ITN 8–10](tasks/ITN_Module_8-10.pptx), 33–34 |
| `exit` | В режиме настройки возвращает на один уровень выше. | [ITN 2–3](tasks/ITN_Module_2-3.pptx), 8 |
| `end` | Из любого режима настройки возвращает в привилегированный режим EXEC. | [SRWE 1–4](tasks/SRWE_Module_1-4.pptx), 3 |
| `write memory` | Сохраняет текущую конфигурацию для следующей загрузки устройства. | — |

## Статическая маршрутизация

| Общий синтаксис | Назначение | Презентация и слайд |
|---|---|---|
| `ip route <сеть назначения> <маска> <IP следующего узла> [<AD>]` | Задаёт статический IPv4-маршрут через указанный узел. Административное расстояние (AD) по умолчанию равно 1. Для резервного маршрута к тому же префиксу задают большее AD, чем у основного. | — |

## HSRP

Команды вводятся в режиме настройки интерфейса. Параметр `<группа>` обозначает номер группы HSRP.

| Общий синтаксис | Назначение | Презентация и слайд |
|---|---|---|
| `standby <группа> ip <виртуальный IPv4-адрес>` | Задаёт общий адрес группы, который узлы сети могут использовать как шлюз по умолчанию. | [SRWE 7–9](tasks/SRWE_Module_7-9.pptx), 42 |
| `standby <группа> priority <приоритет>` | Задаёт приоритет маршрутизатора в группе. При выборе активного маршрутизатора предпочтение получает участник с большим приоритетом. | [SRWE 7–9](tasks/SRWE_Module_7-9.pptx), 40, 42 |
| `standby <группа> preempt` | Разрешает маршрутизатору принять роль Active, если его приоритет выше, чем у текущего активного маршрутизатора. | [SRWE 7–9](tasks/SRWE_Module_7-9.pptx), 41–42 |
| `standby <группа> track <интерфейс> [<величина снижения>]` | Включает отслеживание интерфейса. При его отказе приоритет маршрутизатора снижается на указанную величину (по умолчанию на 10), а при восстановлении возвращается к прежнему значению. | — |

## Диагностика

| Где выполнить | Общий синтаксис | Назначение | Презентация и слайд |
|---|---|---|---|
| Cisco IOS | `show ip route` | Выводит таблицу IPv4-маршрутизации. Для установленного статического маршрута показывает сеть назначения, административное расстояние и следующий узел или выходной интерфейс. | [ITN 8–10](tasks/ITN_Module_8-10.pptx), 36 |
| Cisco IOS | `show standby brief` | Выводит сводку по группам HSRP, включая состояние, приоритет и виртуальный IP-адрес. | — |
| Командная строка ПК | `ping <адрес назначения>` | Проверяет доступность узла с помощью эхо-запросов и ответов ICMP. | [ITN 11–13](tasks/ITN_Module_11-13.pptx), 56 |
| Командная строка ПК | `tracert <адрес назначения>` | Показывает последовательность переходов к узлу назначения по ответам промежуточных маршрутизаторов. | [ITN 11–13](tasks/ITN_Module_11-13.pptx), 57 |
